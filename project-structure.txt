Dad Knows Dungeons — Project Structure

Adding new content
-------------------
- New campaign  → add a markdown file to src/campaigns/
- New journal post → add a markdown file to src/journal/posts/
- New podcast episode → add a markdown file to src/podcast/episodes/
No HTML editing required for any of the above — front matter + Markdown only.
