Every GM has done this: a player asks to talk to a background NPC, you blurt out a name, and now that name has to have opinions, a voice, and possibly a stake in the plot. Here's what actually helps in the moment.

## 1. Steal a voice, not a character

You don't need a fully formed person — you need a distinct way of talking. Clipped sentences. Always answers a question with a question. Over-explains everything. Pick one verbal tic and the NPC feels real even with zero backstory.

## 2. Give them a want, immediately

Every NPC wants something small and concrete: to close the shop early, to avoid a debt collector, to be left alone. That single want tells you how they react to whatever the players do next.

{% callout "tip" %}
"What does this NPC want in the next five minutes" is a much easier question than "who is this NPC," and it's usually enough to run the whole scene.
{% endcallout %}

## 3. Name them last

If you're stalling, describe them first — what they're doing, how they look, how they react to the party walking up — and let the name come after. It buys you a few seconds and it's genuinely how people notice each other.

## 4. Reuse your NPC bench

Keep a running list of names and one-line hooks you've already used in other sessions. Half of "improvising" is just recognizing you've already built the piece you need.

## 5. Let them be forgettable

Not every NPC needs to matter. If the party never asks about them again, that's fine — you don't owe every improvised character a callback.

{% callout "rule" %}
If a name you improvised turns out to matter later, write it down that same session. Future-you will not remember it.
{% endcallout %}
